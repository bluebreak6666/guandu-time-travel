# 關渡時空旅人｜古今穿越互動探索遊戲 (Guandu Time-Traveler)

一套結合**實際地理座標地圖（OpenStreetMap + 中央研究院臺灣百年歷史地圖 WMTS 疊圖）**、**Google 實景街景對照**與**古今原址場景重建**的網頁互動探索遊戲。

## 📍 原址重建三大歷史現場

1. **北淡線關渡火車站及原本巷弄的狀態**
   - **真實原址**：臺北市北投區大度路三段300巷30號（大度路三段296巷與300巷交會處，緊鄰關渡隧道北口，座標 `25.12385°N, 121.46595°E`）。
   - **古今變遷**：明治36年（1903年）設「江頭停車場」，昭和5年（1930年）遷至自臺北起15.1K處，昭和15年（1940年）建木造站房，站門隱於巷內，昔稱「關渡小西門町」。1988年7月15日北淡線停駛後拆除改建捷運，新捷運關渡站北移，舊址化為寧靜巷弄與捷運隔音牆。

2. **知行路開闢之前的關渡老街**
   - **真實原址**：臺北市北投區大度路三段301巷（前段俗稱「店仔尾」至301巷222號關渡玉女宮與關渡宮山門，座標 `25.12055°N, 121.46515°E`）。
   - **古今變遷**：在民國50年代（1960年代）東側「知行路」尚未闢建前，大度路三段301巷是通往關渡宮的唯一石板參道，沿街保有紅磚「亭仔腳」（如301巷23號），每逢關渡媽祖出巡，居民於門前擺設香案夾道迎駕。知行路開通後商圈外移，301巷轉為靜謐坡道住宅巷弄。

3. **關渡宮和關渡碼頭的舊貌**
   - **真實原址**：臺北市北投區知行路360號（關渡宮三川殿前廣場、中港河渡船頭與關渡棧橋碼頭，座標 `25.11805°N, 121.46375°E`）。
   - **古今變遷**：昔日關渡宮（靈山廟）古樸三川殿直接臨水，廟埕石階即為中港河渡船頭，無高聳水泥防洪堤與跨港自行車橋阻隔；四季木造舢舨船進出捕魚、岸邊設「鴨母寮」產紅仁鹹鴨蛋，河口可見淡水河與基隆河交會的「關渡分潮」奇景。

## 🚀 快速發佈至 GitHub Pages

### 方法一：網頁直接上傳（免指令）
1. 在 GitHub 建立一個新的 Public Repository（例如 `guandu-time-travel`）。
2. 將本專案中的 `index.html`、`README.md`、`.nojekyll` 與 `.github/workflows/deploy.yml` 上傳至儲存庫根目錄。
3. 前往 **Settings → Pages**，在 **Build and deployment** 選擇 `Deploy from a branch` → `main` 分支 `/ (root)`，按 **Save**。
4. 等待約 1 分鐘後即可造訪 `https://<您的帳號>.github.io/guandu-time-travel/` 開始遊玩！

### 方法二：Git 指令推送
```bash
git init
git branch -M main
git add .
git commit -m "feat: 發佈關渡時空旅人古今穿越互動遊戲"
git remote add origin https://github.com/<您的帳號>/guandu-time-travel.git
git push -u origin main
```
