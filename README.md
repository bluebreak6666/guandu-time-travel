# 關渡時空旅人 3D

以 Three.js / WebGL 製作的第三人稱 3D 探索遊戲，可直接於 GitHub Pages 執行。

- 三個立體場景：舊關渡車站、石板老街、關渡宮河岸。
- 同位置切換 1960 / 2026 意象環境。
- 角色移動、相機旋轉與縮放、建築碰撞。
- 九個記憶碎片、調查手札、瀏覽器本機存檔。
- 手機方向按鈕與拖曳鏡頭。

操作：WASD / 方向鍵移動；拖曳旋轉鏡頭；滾輪縮放；E 調查；空白鍵穿越。

本作為風格化歷史意象，非精確建築、座標或年代復原。原版地圖與史料入口保留於 original-2d.html。

進度儲存於 localStorage，不跨裝置同步。需支援 WebGL，首次載入需要網路下載 Three.js。GitHub Pages 使用 main 分支根目錄發布。
